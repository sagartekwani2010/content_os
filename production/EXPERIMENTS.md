# Reel experiments

Every reel from 19 Nov 2026 tests at least one hypothesis. A test changes one thing (hook type, emotional tone,
length, format, CTA) and keeps the body the same, so the result says something about that one thing. Results
feed the hook and tone choices of later reels; a pattern needs about three agreeing results before it becomes a
default in `REEL_DEFAULTS.md`.

## How a test runs on Instagram

- Post both variants as Trial Reels (non-followers only) within the same few hours, same caption, cover and time
  slot. Read results at 24 h and 48 h. Share the winner to followers; it becomes the main reel.
- If one variant must go out as the main post straight away, note that its numbers include followers and compare
  only the share of non-follower reach.
- Decide on, in order: 3-second hold, average watch time, sends per reach. Then saves and comment-keyword count
  (the reel's own CTA). A difference under about 10% relative is a tie; log it as one.
- Never change a variant after posting. Record the numbers from Instagram Insights, not from memory.

## Hypotheses to work through

| Axis | Values to compare |
|---|---|
| Hook type | money/value, fear/stakes, wonder, question, personal test, contrarian |
| Emotional tone | positive (curiosity, empowerment) vs fear (stakes, risk) |
| Opening subject | the creator's own result vs an outside fact |
| Length | about 60 s vs about 85 s |
| CTA | comment keyword vs save prompt vs follow for the next episode |
| Format | split diagrams + talking head vs full-screen demo |
