# Travel Ops Visual Prompts — First Pass (Rejected)

These are the exact prompts used for the first image-generation pass. They are retained for traceability only; the resulting assets were rejected because they read as generic AI visuals rather than credible product evidence.

## 01 — Cancelled flight cover

```text
Use case: photorealistic-natural
Asset type: Instagram carousel cover visual, 4:5 portrait composition
Primary request: cinematic, believable travel-disruption scene for an AI travel operations story. A young Indian business traveller in a modern airport terminal, seen over the shoulder holding a phone while looking at a large departure board with one flight visibly marked cancelled using a simple red status bar (no readable airline name, no readable city names, no logos). On the phone: an elegant dark travel-support app interface with an abstract glowing route timeline and assistant activity indicator, but absolutely no readable text.
Scene/backdrop: premium international airport, departure gates, subtle crowd blur, night travel atmosphere.
Style/medium: high-end editorial product photography, real human, natural materials and lighting.
Composition/framing: portrait 4:5, subject and phone on lower right, generous uncluttered dark negative space in the upper left for a title overlay.
Lighting/mood: cinematic blue-black terminal lighting with a controlled warm/red cancellation accent.
Constraints: believable, grounded, sophisticated, no generic robot, no holographic human, no visible brand identity, no watermark, no gibberish text, no title text baked into the image.
Avoid: stock-photo smile, excessive neon, sci-fi spaceship aesthetic, tiny unreadable UI labels.
```

## 02 — Agent trace console

```text
Use case: ui-mockup
Asset type: Instagram carousel interior slide, 4:5 portrait visual
Primary request: a convincing dark-mode travel operations console showing a multi-agent incident trace for a cancelled flight, as if it is a working internal product demo. Left panel: a passenger disruption case card with a red cancellation status band, route shown only as abstract city dots and a route line, no real airline or city names. Main panel: sequential execution trace with four clear colored nodes represented by simple icons and short non-readable placeholder bars: orchestrator, trip context, options search, policy check. Right panel: compact tool-call cards with small code-like lines and success checks. Bottom panel: a deterministic workflow timeline ending in a human-escalation branch.
Style/medium: premium realistic SaaS product UI screenshot, clean typography-like shapes but no actual readable text because no gibberish text is allowed.
Composition/framing: centered dashboard floating against a deep charcoal background, portrait 4:5, crisp enough to crop for carousel.
Lighting/mood: restrained navy, charcoal, cyan, violet and one clear red alert accent; sophisticated enterprise software, not cyberpunk.
Constraints: no logos, no brand names, no watermark, no fake readable text, no person, no generic robot imagery. The visual must communicate agent orchestration, tools and workflow handoff through layout and icons alone.
Avoid: messy UI, tiny paragraphs, excessive glowing lines, code-wall aesthetic.
```

## 03 — Multi-agent architecture

```text
Use case: infographic-diagram
Asset type: Instagram carousel architecture diagram, 4:5 portrait composition
Primary request: a polished, editorial architecture diagram for an illustrative AI travel-operations system. Show a clear vertical flow of six large connected visual modules with simple universally understandable icons only, no readable words: cancelled flight alert card at top; a central orchestration hub; three parallel specialist pods for itinerary/context, alternate-flight search, and policy validation; a row of external tool icons beneath (database, route map, ticket, payment shield); a deterministic workflow rail that locks a seat, confirms booking, notifies passenger; a final human-escalation branch in red. Use visible directional arrows and distinct module grouping so a designer can add labels later.
Style/medium: refined flat-plus-subtle-3D product infographic, not cartoonish, no robot characters.
Composition/framing: portrait 4:5 with generous breathing room, centered hierarchy, each module large enough for a carousel viewer; black/ink background.
Lighting/mood: sophisticated dark navy interface, cyan for orchestration, violet for specialist agents, teal for tools, amber for workflow, and red only for human escalation.
Constraints: diagram must be legible without any text; no logos, no airline brand, no watermark, no gibberish text, no code snippets, no decorative clutter.
Avoid: generic circuit-board imagery, sci-fi city, tiny labels, over-complex network mesh.
```

## Recommended next visual approach

Use a real, locally built Travel Ops Console for all proof slides: readable synthetic incident data, visible agent trace, actual tool-call states, and an explicit workflow handoff. Capture screenshots and a short screen recording from that prototype. Reserve image generation, if any, for an editorial cover only.
