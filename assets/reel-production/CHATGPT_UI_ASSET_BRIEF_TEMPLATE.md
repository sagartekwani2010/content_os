# ChatGPT UI asset brief — Reel production

Use one complete brief per generated visual. The person generating it should be
able to paste this into the ChatGPT UI and receive a usable first pass without
opening a second design tool.

## Required fields

```text
SCENE PURPOSE
What this visual proves in the story. Not the topic—what the viewer should now
believe after seeing it.

SOURCE MATERIALS
Exactly which real photos, product pages, screenshots, or reference images to
upload. Say “none” only when there are no references.

FINAL PROMPT
Create a finished 9:16 [image/video] for an Instagram Reel.

Subject: [exact object/person/system]
Story beat: [what changes from start to end]
Environment: [specific, real-world setting]
Camera + composition: [framing, lens feel, subject position, safe space]
Lighting + texture: [specific visual language]
Required visible evidence: [thing that proves the claim]
On-screen copy: render exactly: “[copy]” OR “no generated text”.
For video: start state → movement/change → end state. Duration: [x] seconds.

DO NOT INCLUDE
[specific forbidden artefacts: fake dashboards, robots, tiny illegible text,
brand logos, extra fingers, generic neon AI imagery, etc.]
```

## Quality rules

- Generate the image/video in the **ChatGPT UI** when that is where the creator
  gets the stronger result. The content system produces the full brief; it does
  not force a lower-quality rendering surface.
- Reference images are evidence, not optional inspiration. Use real wardrobe,
  product, screen-recording, or human material whenever the Reel makes a claim.
- Do not generate a generic “AI interface” to stand in for a real product flow.
- Ask for only one visual event per generated clip. A six-second clip should
  have a legible start, one change, and a legible end.
- If exact text must appear, include the final copy in the prompt. If it would
  be small or dense, use no generated text and make the visual carry the point.
