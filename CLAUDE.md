# Content OS: Claude Code entry point

`AGENTS.md` holds the operating instructions for this repository and applies to Claude Code as well as
Codex. Read it first, then:

1. `CURRENT_REEL_CONTEXT.md`: the current reels and where things stand.
2. `planning/reel-production-system-blueprint-2026-11-15.md`: the production pipeline being built.
3. `feedback/learning-mission-final-edit-diagnosis-2026-11-15.md`: why the last reel fell short.
4. `.agents/skills/reel-footage-edit/` (with `references/edits-automation.md`) before any edit, and
   `.agents/skills/reel-script-writing/` before any script.
5. `production/RECORDING_KIT.md` when planning a shoot; `production/SETUP_NEW_LAPTOP.md` on a new Mac.
6. `WORKSTATION_MIGRATION_HANDOFF.md` before moving creator media from the work Mac to the home Mac. The private release is uploaded and verified; download and restore it on the home Mac.

## Rules that hold in every session

- Follow the pipeline stage by stage. Do not edit before the brief and beat sheet are approved.
- Claude cannot hear audio. Never call a reel done before the creator has listened to the final file.
- Report measured facts (durations, loudness, face jumps, transcripts) and say what was not checked.
- No mid-sentence splices. If a line has no clean take, ask for a re-record.
- No invented screenshots, messages or headlines. Other people's messages are cropped to the text,
  with no names, handles or photos.
- Deliver one finished MP4 per reel with mastered voice, sound effects and music in the same file.
- This repository is public. Footage, exports, audio, message screenshots, databases and credentials
  never go into Git. Never write the Edits token into a file.
- Start a new session per reel and work from that reel's files.
