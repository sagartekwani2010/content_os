# HOOKS

All three play over the same K1 ghost image, so the test isolates the spoken line.

1. **Curiosity (control, used above):** "I gave an AI every workout I've filmed."
2. **Regret:** "I should never have done this set, and an AI caught it." Beat 2 becomes "I gave it every workout I've filmed, and it flagged [N_STOP: one]."
3. **Self-deprecation:** "My AI counted fourteen reps on an eleven-rep set." Beat 2 becomes "It still caught [N_STOP: one] set I should never have done."

**A/B hypothesis for EXPERIMENTS.md:** On Trial Reels to non-followers, the regret hook (2) will beat the curiosity hook (1) on 3-second hold, because a personal mistake over the red gap lands faster than a tech premise. The self-deprecation hook (3) will hold fewer strangers but earn the most comments per view, because an admitted error invites replies. Pick the winner on 3-second hold, with saves per reach as the tie-break, and post it to the main grid.
