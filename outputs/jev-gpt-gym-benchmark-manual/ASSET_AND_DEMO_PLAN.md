## Delivery rule

This Reel uses **Sagar on camera for the narrative** and **GPT-2.5 still images
for every proof/explainer visual**. There are no generated-video shots and no
terminal/code-run captures in this edit. H3 is therefore not used.

Every prompt is ready to run in the ChatGPT UI and is stored in
`GPT_2_5_IMAGE_PROMPTS.md`. These are experiment visuals, not fake product
screens: each image shows one constrained test concept at phone-readable scale.
