# GPT-2.5 image prompts — Hybrid Gym Assistant Reel

## How to use these

Generate each prompt separately in the ChatGPT mobile app. Every prompt asks
for a finished, edit-ready **9:16 image**; there is no Figma or manual text
overlay step. Keep the images in the listed sequence and use the supplied file
names.

### Shared visual language

- 1080 × 1920 vertical, premium editorial systems-explainer, high-quality
  commercial design—not sci-fi.
- Warm off-white, subtly textured paper background; charcoal/ink typography;
  electric blue for GPT and routing; muted lime only for Jev/hybrid; muted
  amber/red only for risk/boundary states.
- Spacious hierarchy, very large legible type, centred layouts, soft natural
  shadows, physical paper-card depth, clean blue connector lines.
- Render **only** the exact specified copy. No extra title, explanation,
  disclaimer, watermark, logo, robot, chat bubble, code, browser chrome,
  chart, or dashboard.
