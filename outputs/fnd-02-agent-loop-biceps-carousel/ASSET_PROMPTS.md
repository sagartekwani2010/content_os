# ChatGPT image-generation context and prompts

## How to use this pack

1. Start one ChatGPT conversation so the design system remains consistent.
2. Upload the five real personal images in chronological order and name them:
   `BEFORE`, `EARLY`, `MID`, `RECENT`, `CURRENT`.
3. Paste the **Master context** once.
4. Replace every `{{PLACEHOLDER}}` below with real values from the programme and
   logs. Do not ask ChatGPT to invent them.
5. Generate one slide at a time using the corresponding prompt.
6. If text is misspelled or the photograph is altered, ask ChatGPT to correct
   only that defect while preserving the approved composition.

emphasising the actual short-head or long-head movement in Sagar's programme,
or adjusting hammer-curl work. Use only the real exercises and changes that
appeared in the source programme or trace.
